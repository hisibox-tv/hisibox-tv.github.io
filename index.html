Ключевые особенности сборки

01 / SYSTEM

Облегчённая система

Удалён предустановленный рекламный мусор, освобождено более 400 МБ в /system.

02 / INTERFACE

LazyIPTV Deluxe

Модифицированный лаунчер по умолчанию с поддержкой кнопки HOME.

03 / APPS

Автоустановка

Vimu, File Manager +, atvTools Server и LeanKey Keyboard устанавливаются автоматически.

04 / ACCESS

Superuser

Root-доступ встроен в прошивку.

05 / LOCALE

Русский интерфейс

Системная локаль ru-RU выставлена по умолчанию.

06 / FLASH

Бережная разметка

XML не перезаписывает fastboot и индивидуальные разделы платы.

Важно перед прошивкой. Снимите полный дамп оригинальных разделов через HiTool. Особенно сохраните deviceinfo, securestore, baseparam и pqparam. Прошивка выполняется на ваш страх и риск.
